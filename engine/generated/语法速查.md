## 4. 复合键（空值 + 缩进子项）

> 🟥 引擎只认**空值 + 缩进子项**；主行带值或被静默忽略（lint 已拦截）。子项必须 `- 子键=值` 前缀。

- **`items:`**（L08、L12b、L18、L25、L26）。子项：`ic`=L08 图标（Lucide 名，不用 emoji）；`t`=主词/标题；`d`=说明；`ch`=L12b 链节点名；`form`=L18 字形；`mean`=L18 释义；`blank`=L12b 留白（裸词 blank，无等号）；`year`=L25 年份；`title`=L25 节点标题；`desc`=L25 描述；`main`=L26 主词；`sub`=L26 副词；`accent`=是否 accent（是/否）。规则：空值 + 缩进子项 `- k=v / k2=v2`；主行带值会被静默忽略
- **`stats:`**（L04、L19、L20）。子项：`label`=标签；`nb`=数值（L19 决定条宽 / L20 决定柱高）；`unit`=单位；`note`=备注；`accent`=显式上色（是/否/红/关）；缺省由强调锚点推导。规则：空值 + 缩进子项；L19/L20 须同单位可比
- **`steps:`**（L13、L21）。子项：`title`=步骤名（L21 环上节点）；`desc`=步骤说明。规则：空值 + 缩进子项；L13 序号引擎自动（nb= 不生效）
- **`rows:`**（L06）。子项：`k`=年份/键；`v`=内容；`m`=备注。规则：空值 + 缩进子项；行 >6 或 v= 过长会压字
- **`imgs:`**（L23）。子项：`file`=图片路径；`cap`=图注。规则：空值 + 缩进子项；同组图须同类、同比例；路径走与单图相同的安全校验
- **`kpis:`**（L27）。子项：`v`=数值；`l`=标签。规则：空值 + 缩进子项；最多 3 个

- **`size`**：字号标记。命名档位 大/中/小（未闭合=整段、成对=局部）；**显式数字倍数 <size=1.5> 亦支持**（float 成功 → font-size:Xem，_size_span L1147-1160，局部与整段均可）。
- **`align`**：整段对齐 <align=居中/居左/居右>（未闭合）。
- **`bold`**：**加粗**。
- **`ico`**：行内图标 <ico=名>（Lucide）。
- **`step`**：分步揭示 |||（先问后揭；仅 M10 正文/notes/列表）。

## 8. 斜杠规则

- 两侧带空白的 / 或 ／ 才是分行/分项符；贴字斜杠（唐/突厥）是内容不切；保护 </xxx> 结束标签内斜杠。
