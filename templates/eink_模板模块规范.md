## 0. 设计令牌（主题可配，默认 ink-classic 墨水经典）

> ⚠️ **本引擎是通用的，不绑定任何单一主题。** 下面 `--ink / --paper / --accent` 三色**随所选主题变化**。
> 写大纲、画 SVG、改样式时**一律引用变量名**（`currentColor` / `var(--accent)`），**严禁写死 hex**——否则换主题即失效。

|---|---|---|---|---|---|

| `indigo` | 靛蓝瓷 | `#0a1f3d` | `#f1f3f5` | `#d98324` 暖琥珀 | 无衬线 |
| `forest` | 森林墨 | `#1a2e1f` | `#f5f1e8` | `#b8842f` 金 | 衬线 |

固定令牌（与主题无关）：

| 令牌 | 值 | 含义 |
|---|---|---|
| `--accent-ink` | 随主题 | dark 页强调色（保可读），如 kraft 为 `#d65436` |

**配色铁律**：整页只用「墨 + 纸 + accent」三色体系；accent 只点关键数字 / 引文 / 关键词，克制。

## 1. 四角布局（终版规则，全系列一致）

- **左上 `M01` 顶左眉标**：**每一页都显示**，内容是**逐页变化的运行标签**，不填则该角空白。
- **右上 `M02` 讲稿题目**：自动取大纲顶部「讲稿题目(M02)」；**仅封面(L01)隐藏**，章节扉页(L02)/收束(L15)/内页全显示。
- **左下 `M03` 块·内容**：**仅封面(L01)隐藏**；章节扉页/收束/内页均显示。
- **右下 `M04` 页码**：自动 `NN / 总 · 系列名`；**仅封面(L01)隐藏**。

> 一句话：**只有封面(L01)隐藏 M02/M03/M04；M01 永远显示；其余页四角全显。**

## 3. 视觉 / 样板细节（已核实采纳）

- **分隔线层级**：主分割 `.25`、次分割 `.15`。
- **图标统一**：`ico-lg`/`ico-md` 固定比例；用 Lucide 线性图标，不用 emoji。
- **导航圆点**：base `8px→~10px`，active `22px→28px`。
- **翻页 transition**：`.6s`。
- **字号下限**：多数已用 `max(px,vw)` 地板；大显示字号加 `clamp()` 防溢出。

## 4. 版式默认动效（大纲可用 `data_animate:` 局部覆盖）

| 版式 | 默认 `data-animate` | 行为 |
|---|---|---|
| L01/L02/L15 hero | `hero` | 慢 stagger 淡入 |
| L07 quote | `quote` | q-big 逐行揭示 |
| L09 split | `directional` | 左→右顺序入场 |
| L13 pipeline | `pipeline` | 空格/`→` 手动步进 |
| L19 条形图 | `hbar` | 柱 `scaleX` 拉开 + 数字递增 |
| L20 KPI塔 | `kpitower` | 柱 `scaleY` 长高 + 数字递增 |
| L21 闭环图 | `loop` | 圆环描线 + 节点弹入 + 步骤左移 |
| L22 系统同心圆 | `system` | 三层圆由外向内放大入 |
| L23 多图证据墙 | `wall` | 瓦片依次上移淡入 |
| L24 论断 / L25 时间轴 / L26 微卡 / L27 图幅 | `cascade` | 一次性淡入（无专属 recipe） |
| 其余 | `cascade` | 一次性淡入 |

> 共 10 种 recipe：`cascade`/`hero`/`quote`/`directional`/`pipeline`（通用，可套任意页）＋ `hbar`/`kpitower`/`loop`/`system`/`wall`（专属，仅对应版式有专属动画）。  
> 套用边界：专属 recipe 套到非对应版式时，专属标记不存在，只剩通用元件淡入兜底（不报错）。详见 SKILL.md「动效全表」。
